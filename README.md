### Примеры запуска тестов на разных окружениях

- **Dev окружение:**  
  `pytest -s --env=dev`

- **Stage окружение:**  
  `pytest -s --env=stage`

### Как открыть Allure-отчёт

После выполнения тестов в корне проекта появится папка `allure-results`.  
Для генерации и открытия отчёта выполнить:

`allure serve`
