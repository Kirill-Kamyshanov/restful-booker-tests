## Фреймворк для автоматизированного тестирования сервиса Restful-booker

Официальная документация с инструкцией для генерации токена:
https://restful-booker.herokuapp.com/apidoc/index.html

## Локальный запуск тестов в IDE

#### 1. Установка зависимостей
```
pip install -r requirements.txt - шаг 1. Установка зависимостей
pre-commit install - шаг 2. Скачивание хуков для применения конфигурации линтера к каждому коммиту. Новый код будет гарантированно форматирован согласно стандартам проекта
```

---
#### 2. Определение секретов проекта
Cоздать в корне проекта .env файл в формате:
```dotenv
AUTHORIZATION='токен'
BOOKER_USERNAME="юзер"
BOOKER_PASSWORD="пароль"
```



#### 3.Запуск тестов
Примеры конфигураций запуска:
```
pytest           - стандартный запуск. Флаги из конфига добавятся автоматически
pytest --env=dev - запуск в определённом окружении
pytest -m smoke  - запуск группы маркированных тестов
```


---
## Запуск тестов в Docker-контейнере

Перед запуском тестов в контейнере необходимо настроить переменные окружения.

#### Переменные окружения для запуска:
- AUTHORIZATION (авторизационный токен. Обязательный)
- ENV (тестовое окружение. Опционально. По умолчанию 'dev')
- BOOKER_USERNAME (юзер)
- BOOKER_PASSWORD (пароль)


#### Примеры команд для запуска сервиса:
```
docker-compose up                 - стандартный запуск всех тестов по умолчанию
docker-compose up --build         - запуск тестов с пересборкой docker-образа (при внесении изменений в Dockerfile)
docker-compose run tests -m smoke - запуск тестов с определённым маркером 
```

---
### Получение доступа к allure-отчёту
После запуска тестов любыми указанными выше способами результаты будут доступны вне контейнера в папке /allure-results
```
allure serve     - просмотр на локальном сервере
allure generate -c allure-results -o allure-report allure-results - генерация файлов с отчётами
```

## Запуск тестов в CI/CD Pipeline
CI/CD Pipeline автоматически запускает тесты при PR в ветку 'main', генерирует Allure-отчёт и публикует его на GitHub Pages. 
Отчёт доступен даже при падении тестов.
